写在前面

不是所有翻墙，都需要一声巨响

GoCats 的名字来自一个很朴素的观察：猫从来不为翻墙这件事做动员，它只是在某个午后的窗台上伸了个懒腰，然后轻巧地落到了另一边。我们把这种姿态，放进了网络线路的调度里。

这意味着我们不会在首页堆满“极速”“秒开”“全球节点覆盖两百国”这类无从验证的形容词。线路是租来的，带宽是有限的，协议是公开的，猫也是会打盹的。我们更愿意告诉你：每月 100GB 的基础流量，足够让一个人在通勤路上把订阅列表刷完，再看两部老电影；300GB 的旗舰档，则能撑起一家三口各自抱着平板追剧的夜晚。

如果你愿意把网络托付给一只猫，那接下来的文字，就是它的饲养手册。

它能做什么

三个方向，够了

让网页先抵达，再说话

GoCats 的线路调度优先保障首屏加载与 API 响应，而不是一味追求测速数字。对日常浏览、文档协同和即时通讯而言，延迟的稳定性比峰值带宽更影响体感。

对流媒体保持友好

旗舰版与团队版标注了“原生流媒体解锁”，指的是我们在部分节点上尽量使出口 IP 与服务方预期的地区一致，以减少被识别为代理的概率。这不等于永久保证，平台策略随时可能变动。

给游戏留一条专线

旗舰版及以上包含 IPLC 专线加速优化，主要面向跨境延迟敏感的场景，如海外游戏联机、远程桌面与实时直播。专线带宽有限，按公平使用原则调度。

使用说明

四步，把猫领回家

  1. 选择一档方案

    从基础版、旗舰版、团队版中选一个与你的使用强度匹配的档位。月付用于试用，年付更适合已经决定长期使用的人。

  2. 完成订阅与开通

    付款后系统通常在几分钟内开通，订阅地址与节点列表会通过邮件发送。若超过 30 分钟未收到，请先检查垃圾箱，再提交工单。

  3. 导入客户端

    在对应平台的客户端中粘贴订阅链接，更新节点列表。首次使用建议手动选择一个延迟较低的节点，再开启全局或分流模式。

  4. 按需调整，保持安静

    GoCats 的线路会不定期维护与扩容，客户端会随订阅更新自动获取。无需频繁手动干预，像猫一样，放着就好。

常见问题

猫偶尔也会被问到的几件事

  1. GoCats 是否承诺“绝不日志”？

    我们不记录用户的浏览内容、DNS 查询与访问目标。但在技术层面，会保留连接时间与流量统计，用于计费与故障排查。这是当前所有按流量计费服务的客观需要，与营销话术无关。

  2. 流量用完之后会断网吗？

    不会立刻断开。当月极速流量耗尽后，连接仍可保持，但速率会被调低至保障通道水平，通常足够收发邮件与文字浏览，不适合视频与大文件下载。

  3. 为什么有时节点延迟比宣传的高？

    节点延迟受本地运营商、跨境路由与目标服务器共同影响，首页与测速截图通常是在最优条件下取得的参考值。GoCats 不把单次测速作为服务质量承诺，建议以连续三日的使用体感为准。

  4. 可以同时用多少台设备？

    基础版 3 台、旗舰版 5 台、团队版 20 台。同一订阅地址在超出限额后，新连接会把旧连接挤下线，不会产生额外费用，但会导致设备频繁掉线，建议按需配置。

  5. 订阅后可以退款吗？

    GoCats 目前不提供无理由退款。若开通后 24 小内因节点不可用导致完全无法连接，可凭工单与日志截图申请等额流量补偿或方案调整，不退还现金。

  6. GoCats 适合用来做什么？

    日常浏览、跨境文档协同、海外流媒体观看、远程办公与游戏联机，是 GoCats 的主要设计场景。我们不承诺、也不鼓励用于任何违反所在地法律或目标服务条款的用途。
